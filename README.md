# Hashtag Copier

Небольшая программа для Windows для быстрого копирования хештегов из личной базы. Все хештеги хранятся в виде кнопок — кликнул, и текст уже в буфере обмена.

## Возможности

- 🗂 **База франшиз и персонажей** — хранится локально в `%APPDATA%\HashtagCopier\data.json`
- 🎯 **Копирование в один клик** — хештег сразу попадает в буфер обмена
- ➕ **Адаптивная кнопка добавления** — «Добавить франшизу» / «Добавить персонажа» в зависимости от того, где вы находитесь
- ✏️ **Редактирование и удаление** — через правый клик по кнопке
- 🔢 **Счётчик кликов** — видно, как часто используется каждая кнопка
- 📊 **Автосортировка по популярности** — самые используемые кнопки всегда сверху
- 🔍 **Поиск** — работает и для франшиз, и для персонажей
- 📈 **Статистика топ-3** — слева внизу, обновляется в реальном времени
- 💾 **Импорт/Экспорт** — вся база сохраняется в JSON, легко переносить между устройствами
- ⚙️ **Обязательная часть** — многострочный шаблон (например, «Автор: #anime #art»), копируется одной кнопкой
- 🏷 **Тег сообщества по умолчанию** — подставляется при добавлении персонажей
- 📌 **Поверх всех окон** — переключатель в левой панели
- ⌨️ **Глобальный хоткей `Ctrl+Shift+H`** — вызвать/скрыть окно из любой программы
- ⌨️ **ESC** — вернуться к списку франшиз

## Формат хештегов

- **Франшиза:** `#bocchi_the_rock`
- **Персонаж:** `#Nijika_Ijichi@public_name`

Где `Nijika_Ijichi` — хештег персонажа, а `public_name` — тег сообщества.

## Системные требования

- **Windows 10** или новее (x64)
- Если используется вариант сборки **без .NET внутри** — потребуется [.NET 8 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

## Установка

### Готовый `.exe`

1. Скачай последний релиз со страницы [Releases](../../releases).
2. Распакуй архив в удобное место.
3. Запусти `HashtagCopier.exe`.

### Сборка из исходников

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
git clone https://github.com/Oghat54/HashtagCopier.git
cd HashtagCopier
dotnet run
```

### Сборка `.exe` (один файл)

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Готовый `.exe` появится в `bin\Release\net8.0-windows\win-x64\publish\HashtagCopier.exe`.

## Использование

### Основные действия

| Действие | Результат |
|---|---|
| ЛКМ по кнопке франшизы | Копирует `#хештег_франшизы` и переходит к персонажам |
| ЛКМ по кнопке персонажа | Копирует `#персонаж@тег_сообщества` |
| ПКМ по кнопке | Меню: изменить / сбросить счётчик / удалить |
| ESC | Вернуться к списку франшиз |
| `Ctrl+Shift+H` | Показать/скрыть окно из любой программы |
| Начать печатать | Фокус переходит в поиск, кнопки фильтруются |

### Добавление

Кнопка в левой панели меняет название в зависимости от контекста:
- В меню франшиз → «Добавить франшизу».
- В меню персонажей → «Добавить персонажа».

В диалоге есть автозаполнение: хештег подставляется из имени автоматически, пока ты сам не начнёшь его править.

### Обязательная часть

Кнопка сверху в левой панели копирует шаблон, заданный в настройках (например, `Автор:\n#anime #art`). Редактируется через ПКМ → «Изменить».

## Где хранятся данные

Вся база — в одном JSON-файле:

```
%APPDATA%\HashtagCopier\data.json
```

Структура:

```json
{
  "DefaultCommunityTag": "public_name",
  "MandatoryPart": "Автор:\n#anime #art",
  "Franchises": [
    {
      "Name": "БОЧИ ЗЕ РОК",
      "Hashtag": "bocchi_the_rock",
      "ClickCount": 0,
      "Characters": [
        {
          "Name": "НИДЖИКА",
          "Hashtag": "Nijika_Ijichi",
          "CommunityTag": "public_name",
          "ClickCount": 0
        }
      ]
    }
  ]
}
```

## Импорт / Экспорт

Через кнопку **Импорт/Экспорт** в левой панели:

- **Экспорт** — сохраняет всю базу в `.json`.
- **Импорт** — загружает базу из файла. Можно **заменить** текущую или **объединить** с ней.

При объединении:
- Франшизы с одинаковым именем не дублируются.
- Персонажи с одинаковым именем внутри франшизы не дублируются.
- Тег сообщества из импортируемого файла обновляется, если он непустой.

## Технологии

- **C# / .NET 8**
- **WPF** (Windows Presentation Foundation)
